# Flower-of-Life GOD Engine

A self-referential fractal framework for symbolic mathematical exploration.

## Overview

The GOD Engine is a Python system that generates beautiful, self-consistent LaTeX treatises using a fractal Sierpiński sieve, golden-ratio algebra from √(3-4i), Cantor dust bridges, and an honesty dial (y′) that lets you switch between rigorous mode (y′=1) and pure symbolic/god mode (y′=0).

## Key Features

- **Honesty Dial (y′)**: Switch between rigorous mathematical framing and pure symbolic creation at runtime.
- **Petal Generation**: Produce individual 10-page LaTeX petals.
- **Full Treatise Generation**: Generate the complete 1000-page self-deconstructing treatise.
- **Professional Paper**: Includes a rigorously framed scientific paper.

## Quick Start

```bash
git clone https://github.com/BigponsAU/god-engine.git
cd god-engine
pip install -e .

# Generate the full 1000-page treatise in God Mode (y′=0)
python examples/generate_full_treatise.py
```

## The Honesty Dial

- `y_prime = 1`: Rigorous mode (default). The engine is honest about what it can and cannot prove.
- `y_prime = 0`: God/Symbolic mode. Every statement is declared true inside the petal. Metaphor becomes law.
